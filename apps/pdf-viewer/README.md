# Inspekt PDF Viewer

A native macOS/Windows/Linux desktop application for viewing PDF accessibility reports generated by Inspekt.

## Features

- **Drag & Drop** - Drop PDF files to check accessibility or JSON reports to view results
- **Native Look & Feel** - macOS title bar integration, native menus, keyboard shortcuts
- **Comprehensive Reports** - Score visualization, metadata, checks table, content audit, structure tree, and more
- **PDF Integration** - Open the original PDF alongside the report

## Development

### Prerequisites

- [Node.js](https://nodejs.org/) 18+
- [Rust](https://www.rust-lang.org/) 1.77+
- [Tauri CLI](https://tauri.app/v1/guides/getting-started/prerequisites)

### Setup

```bash
# Install dependencies
npm install

# Run in development mode
npm run tauri dev

# Build for production
npm run tauri build
```

## Architecture

### Frontend (Svelte 5)

The UI is built with Svelte 5 using the new runes API for reactivity. Key components:

- **Welcome.svelte** - First-launch welcome screen
- **DropZone.svelte** - File drag-and-drop area
- **ProgressView.svelte** - PDF check progress indicator
- **ReportView.svelte** - Main report viewer with sidebar

### Backend (Rust/Tauri)

The Rust backend provides:

- **File Operations** - Reading JSON reports, file info
- **PDF Checking** - Spawns `inspekt pdf check` subprocess
- **Native Menu** - macOS/Windows/Linux menu bar
- **Drag & Drop** - Native file drop handling

### State Management

Uses Svelte stores for reactive state:

- **preferences** - User preferences (persisted via Tauri Store)
- **report** - Current report data and app state
