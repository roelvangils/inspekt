🚀 Quick Start

  1. Open a terminal
  2. Start the server: inspekt server start
  3. Run commands: inspekt eval "document.title"

✨ Extension Features

  • CSP Bypass: Works on all websites including GitHub, Gmail, banking sites
  • Automatic Connection: Connects to localhost:8766 automatically
  • Domain Whitelisting: You control which sites can be accessed
