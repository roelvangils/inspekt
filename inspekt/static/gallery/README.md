# `static/gallery/` — archived reference files

`gallery.css` and `gallery.js` in this directory are **not wired into any code path**. The image-gallery HTML is generated by `inspekt/services/image_gallery.py` using an inline template, which is the canonical implementation.

These files date from an earlier modular version of the gallery that was disconnected during the April 2026 bulk-commit. They're kept as reference — a few UX niceties (draggable info-panel window positioning, etc.) haven't been ported back into the inline template yet. If you're mining them for features, search here before writing new code.

Safe to delete once their content has been either ported into `image_gallery.py` or confirmed unwanted.
