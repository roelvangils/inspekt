**INSPEKT_VERBOSE**
:   When set to *1*, equivalent to passing **--verbose** to every command.

**INSPEKT_NO_TIPS**
:   When set to *1*, suppresses tips and hints in command output.

**INSPEKT_INSTANCE**
:   Default browser instance ID, alias, or index to target.

**INSPEKT_RESTRICTED**
:   When set to *1*, hides commands that are dangerous in a shared or
    sandboxed terminal (set by the Inspekt VM terminal server).

**ANTHROPIC_API_KEY**, **OPENAI_API_KEY**
:   Used by AI commands such as **inspekt ask** and **inspekt describe**.
