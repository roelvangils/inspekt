Remote DevTools Setup

Connect your local Chrome DevTools to inspect and debug the VM browser.

1 Open Chrome Inspect Page

In your local Chrome browser, navigate to:

chrome://inspect/#devices
2 Configure Network Target

Click "Configure..." next to "Discover network targets" and add:

localhost:9222

If running Docker with port mapping, use the mapped port instead.

3 Connect to Target

The VM browser tabs will appear under "Remote Target". Click "inspect" to open DevTools.

⚠
Security Note: CDP has no authentication. Only expose port 9222 on trusted networks or use SSH tunneling for remote access.
1 Create SSH Tunnel

Run this command on your local machine:

ssh -L 9222:localhost:9222 user@your-server-host

Replace user@your-server-host with your SSH credentials.

2 Open Chrome Inspect Page

With the tunnel active, navigate to:

chrome://inspect/#devices
3 Configure Network Target

Add this target (the tunnel forwards to the VM):

localhost:9222

✓ SSH tunnel encrypts all traffic between your machine and the server.
